# STM32 Hello World: UART, SWO, Semihosting and RTT

A set of minimal STM32H750 examples demonstrating several ways to send text from a microcontroller to a development computer.

The project contains four independent examples of the familiar `Hello, World!` program:

* **UART** — output through a hardware UART;
* **SWO / ITM** — output through the SWO debug interface;
* **Semihosting** — output through the debugger using ARM semihosting;
* **RTT** — output through SEGGER Real-Time Transfer.

The examples are intentionally kept separate so that the implementation and configuration of each output method can be compared directly.

## Hardware

The examples target:

* **MCU:** STM32H750xx
* **Core:** Arm Cortex-M7
* **Debugger:** ST-LINK or SEGGER J-Link
* **IDE/toolchain:** CMake-compatible GCC toolchain

The exact development board is not important as long as the required debug interface and, for the UART example, the corresponding UART pins are available.

## Flashing and debugging

The generated ELF file can be programmed into the STM32H750 using the debugger and the corresponding STM32/SEGGER tools.

For debugging, connect the development board through:

* ST-LINK;
* or SEGGER J-Link.

The exact debugger configuration depends on the selected output method.


## Source configuration

The STM32 projects contain the files generated by STM32CubeMX/CubeMX-compatible tooling:

* `*.ioc` — STM32CubeMX project configuration;
* `Core/` — application and HAL initialization code;
* `Drivers/` — STM32 HAL and CMSIS components;
* `startup_stm32h750xx.s` — Cortex-M7 startup code;
* `STM32H750xx_FLASH.ld` — linker script;
* `CMakeLists.txt` — CMake build configuration;
* `CMakePresets.json` — CMake presets.
